# uniproc-etw

Event Tracing for Windows, shared by [uniproc-windows-agent](https://github.com/uniproc-dev/uniproc-windows-agent) and guinea's devtools profiler.

- `Session`: starts and stops trace sessions, enables providers, reads ETW's counters, changes the flush timer of a running session. A system logger turns on SeSystemProfilePrivilege itself.
- `Trace::real_time`: hands a session's events to a callback on a thread of its own.
- `read_file`: reads the events a session wrote to a file, with the `Clock` its raw timestamps count in.
- `Event`: header fields and raw payload without copies, fields by name through TDH (numbers, UTF-16 and code-page strings, counted or terminated, SIDs), and `to_owned` for reading on another thread.

Nothing of windows-rs crosses the API: a provider is a `u128`.

## What ETW allows

- A private session (`Options::private_in_proc`) needs no administrator but sees only its own process's providers. ETW refuses one in real time (`ERROR_INVALID_PARAMETER` for every combination of flags), so it writes a ring file, read with `read_file` once the session stops.
- ETW does not find a private session by its name; `Session` addresses it by its logger id.
- An ordinary real-time session and a system logger need an administrator.

## Bindings

`src/bindings.rs` is generated by windows-bindgen from `src/bindings.txt`. After changing the filter:

```
UNIPROC_ETW_REGENERATE=1 cargo test --test bindings
```

## Tests

`cargo test` runs everything that needs no administrator, private sessions included. `cargo test -- --ignored --test-threads=1` as an administrator runs the rest.
